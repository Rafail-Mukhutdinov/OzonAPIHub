# Changelog: OzonAPIHub

## [1.1.0] — 2026-02-13
### 🛡️ Безопасность и Multi-tenancy
- ✅ **Изоляция данных**: Добавлена принудительная фильтрация по `user_id` во всех эндпоинтах.
- ✅ **JWT защита**: Все запросы требуют валидный токен в заголовке Authorization.
- ✅ **SaaS-логика**: Создание записей (расходы, ключи) автоматически привязывается к текущему пользователю.

### ⚡ Оптимизация и Аналитика
- ✅ **Фикс дублей имен**: Продажи по одному артикулу (offer_id) теперь схлопываются в одну строку. Система автоматически выбирает самое актуальное (последнее) название товара.
- ✅ **Async/Sync Fix**: Устранена блокировка Event Loop при запросах к БД (перевод на `def` эндпоинты).
- ✅ **Modern FastAPI**: Переход на `lifespan` контекст для управления фоновыми задачами.

### 🪵 Логирование
- ✅ **Раздельные логи**: Общий лог системы (`app.log`) и персональные журналы (`logs/users/user_{id}.log`).
- ✅ **Ротация**: Автоматическая очистка старых логов при достижении лимита (5MB/2MB).
- ✅ **Docker Persistent**: Логи сохраняются в папке проекта на сервере через Docker Volumes.

## [1.0.1] — 2026-01-02
### 🔄 Рефакторизация
- ✅ Миграция на `httpx` (асинхронный HTTP-клиент).
- ✅ Модульная структура `routes/`.
- ✅ Вынос логики синхронизации и обогащения в отдельные сервисы.
