# 🗺️ План развития OzonAPIHub (2026)

Этот документ содержит стратегию развития проекта, технические цели и идеи по улучшению архитектуры.

---

## 🎯 Ближайшие цели (Q1-Q2 2026)

### 1. Стабильность и Безопасность
- [ ] **Alembic**: Внедрение миграций для управления схемой БД PostgreSQL.
- [ ] **Rate Limiting**: Ограничение количества запросов к API.
- [ ] **Redis**: Кеширование ответов Ozon API.

### 2. Аналитика и Финансы
- [ ] **Dashboard v2**: Расширенные графики прибыльности, включая ROI и маржинальность.
- [ ] **Интеграция с расходами**: Автоматический вычет себестоимости (COGS).
- [ ] **Экспорт данных**: Выгрузка отчетов в Excel и PDF.

### 3. Масштабируемость и фоновая обработка [DONE]
- [x] **Параллельная обработка (Worker-ы)**: 
  - Переход на распределенную очередь задач (**ARQ**) на базе Redis.
  - Распараллеливание синхронизации пользователей.
- [x] **Умный интервал (Adaptive Polling)**:
  - Реализован алгоритм адаптивного изменения частоты опроса Ozon API (1/5/15 мин).
- [x] **Smart Gap Filling**:
  - Автоматическая докачка пропущенных данных после простоя сервера.

### 4. Точность аналитики и соответствие Ozon [СЛЕДУЮЩИЙ ЭТАП]
- [ ] **Коррекция времени (Timezone Sync)**: Исправление алгоритмов группировки по датам для исключения "прыжков" заказов между днями (синхронизация полночи по стандартам Ozon).
- [ ] **Фильтрация статусов**: Внедрение исключения отмененных заказов (`cancelled`) из расчетов выручки для 100% совпадения с личным кабинетом Ozon.
- [ ] **Детальная статистика**: Добавление учета расходов и налогов в общую прибыль.

## 📝 Детальная спецификация новой системы синхронизации

### 1. Архитектура "Двух треков" (Double-Track Sync) [DONE]
- **Трек А (Backfill Worker)**: Глубокая загрузка истории (365 дней).
- **Трек Б (Real-time Worker)**: Оперативная синхронизация каждые 1-15 минут.

### 2. Управление через очереди (Task Queue) [DONE]
- Использование ARQ + Redis для изоляции API от тяжелых задач.

### 3. Smart Gap Filling [DONE]
- Автоматическая докачка пропущенных данных после простоя сервера.
