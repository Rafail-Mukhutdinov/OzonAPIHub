# 📱 Flutter Frontend Guide

Инструкция по работе с кроссплатформенным клиентом OzonAPIHub.

---

## 🏗️ Архитектура

Приложение построено на **Provider** для управления состоянием и **Dio** для сетевых запросов.

### Структура проекта
- `lib/providers/auth_provider.dart`: Управление сессией пользователя и JWT токеном.
- `lib/services/api.dart`: Централизованный HTTP-клиент с интерцепторами для автоматической подстановки токена и обработки 401 ошибок.
- `lib/screens/`: Экраны авторизации, регистрации и основной дашборд.

## 🚀 Запуск

### Предварительные условия
- Flutter SDK (последняя стабильная версия)
- Backend запущен на `http://localhost:8080` (или другом адресе)

### Шаги
```bash
cd ozon_sales_dashboard

# Установка зависимостей
flutter pub get

# Запуск в браузере (рекомендуется для тестов)
flutter run -d chrome
```

## 🔒 Авторизация и Безопасность

### JWT Workflow
1. **Вход**: Пользователь вводит логин/пароль -> Получает `access_token`.
2. **Хранение**: Токен сохраняется в `SharedPreferences` (LocalStorage в Web).
3. **Инъекция**: Каждый запрос к API автоматически получает заголовок `Authorization: Bearer <token>`.
4. **Инвалидация**: Если API возвращает `401 Unauthorized`, приложение автоматически очищает токен и перенаправляет пользователя на экран логина.

## 🧪 Тестирование (Checklist)

1.  **Splash Screen**: При запуске должен кратковременно появиться `CheckAuthScreen`.
2.  **Регистрация**: Создайте аккаунт. Убедитесь, что после регистрации вы попали на Dashboard.
3.  **Auto-login**: Закройте вкладку и откройте снова. Вы должны сразу попасть на Dashboard без повторного ввода пароля.
4.  **Logout**: Нажмите кнопку выхода. Убедитесь, что токен удален из LocalStorage (F12 -> Application -> Local Storage).

## 🛠️ Настройка API URL
Если ваш Backend запущен на другом адресе или порту, измените `baseUrl` в `lib/services/api.dart`. Для Android-эмулятора используйте `http://10.0.2.2:8080`.
