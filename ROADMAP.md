# 🗺️ План развития OzonAPIHub

Этот документ содержит стратегию развития проекта, технические цели и идеи по улучшению архитектуры.

---

## 🎯 Ближайшие цели (Q1 2024)

### 1. Стабильность и Безопасность
- [ ] **Alembic**: Внедрение миграций для управления схемой БД PostgreSQL.
- [ ] **Rate Limiting**: Ограничение количества запросов к API для предотвращения злоупотреблений.
- [ ] **Redis**: Перенос сессий и кеширование ответов Ozon API.

### 2. Аналитика и Финансы
- [ ] **Dashboard v2**: Расширенные графики прибыльности (ROI, маржинальность).
- [ ] **Интеграция с расходами**: Автоматический учет логистики и комиссий в итоговом профите.
- [ ] **Экспорт**: Выгрузка отчетов в Excel/PDF.

---

## 🛠️ Технические рекомендации (Техдолг)

### Оптимизация БД
- **Batch Operations**: Текущее обогащение данных идет по одному постингу. Необходимо переписать на массовые (bulk) вставки для ускорения процесса в 5-10 раз.
- **Индексы**: Добавить индексы на часто фильтруемые поля (`created_at`, `status`) в PostgreSQL.

### Мониторинг
- **Логирование**: Переход на структурированный JSON-формат логов для удобного анализа в ELK/Loki.
- **Sentry**: Интеграция для отслеживания ошибок в реальном времени.

### Инфраструктура
- **Docker Compose**: Оптимизация конфигурации для production (разделение сетей, healthchecks).
- **CI/CD**: Настройка GitHub Actions для автоматического тестирования и деплоя.

---

## 💡 Идеи на будущее
- Поддержка других маркетплейсов (Wildberries, Яндекс Маркет).
- Мобильные уведомления о новых заказах через Firebase/Telegram.
